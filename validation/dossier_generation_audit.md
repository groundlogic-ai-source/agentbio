# Dossier generation audit

## Finding

The recurring contradictions were not isolated copy defects. The report renderer
had no single claim-level source of truth. It combined five semantic layers:

1. target-selection values from the Biologist;
2. candidate pharmacology from the Chemist;
3. scoring and missingness decisions from the Reviewer;
4. target-specific context supplied separately to the Writer; and
5. unconstrained free-form rationale that could restate any of the above.

Those layers answer different questions. Rendering similarly named fields as one
fact made internally valid intermediate values become contradictory public
claims.

## Contradiction inventory and root causes

### Open Targets value: observed versus not observed

The pharmacological-precedent target lane stamps a constant solely to order
targets. Reviewer scoring correctly excludes that constant because it is not a
measured Open Targets association. The Writer previously printed the raw
selection value as measured evidence while also printing the Reviewer's
exclusion. The report must use the Reviewer measurement basis as authoritative;
the raw value may appear only as explicitly labelled selection context.

### Target precedent versus disease approval

`clinical_precedent` is a target-discovery tier derived from how the target was
surfaced. It is not candidate regulatory evidence and does not establish approval
for the disease. The Writer added the unsupported phrase “approved for this
disease concept.” Target provenance and compound approval must remain separate.

### ChEMBL mechanism absence versus approved target drugs

The Biologist's ChEMBL mechanism query, activity-based candidate pools,
DrugCentral, GtoPdb, and comparator evidence are different bounded source
universes. An empty ChEMBL mechanism response is only a source-specific absence,
not proof that no approved target-modulating drug exists.

### Conflicting BioGRID/network lists

The structured summary used target-matched network context while free-form
Chemist rationale could carry a different target's or earlier context's list.
Because prose had no typed provenance, the Writer could not reconcile it.
Free-form rationale is therefore not a public evidence surface; structured,
target-matched fields are authoritative.

### Raw tokens and punctuation

Discovery and approval identifiers crossed a serialization boundary as machine
tokens and were printed without display normalization. Directional reasons also
crossed as already-punctuated prose and the Writer appended another period.
Display normalization belongs at the final rendering boundary.

### Universal wet-lab mandate

Safety disclaimers had drifted into workflow instructions: every candidate was
said to require wet-lab and clinical validation, approval automatically advanced
wet-lab work, and rejection permanently closed a case. AgentBio can define what
it has and has not evaluated, but qualified organizations choose whether and how
to pursue a hypothesis. The correct boundary is:

- no treatment recommendation, self-treatment, prescribing, or authorization;
- unknown efficacy, safety, exposure, PK, and applicability remain explicit;
- experiments and other validation are possible organization-selected next
  steps, not universal commands from the software.

## Enforced report invariants

- A precedent-stamped Open Targets value is never described as measured evidence.
- A target discovery tier never implies disease-specific candidate approval.
- An empty bounded source query never becomes a universal nonexistence claim.
- Free-form agent prose cannot restate structured dossier evidence.
- Machine tokens are humanized at the display boundary.
- The dossier does not mandate a particular organizational next step.
- Existing immutable reports remain unchanged; corrected reports are new
  immutable artifacts generated by corrected code.
