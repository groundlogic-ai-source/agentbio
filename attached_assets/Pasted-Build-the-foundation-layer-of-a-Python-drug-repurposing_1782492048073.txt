Build the foundation layer of a Python drug-repurposing research pipeline. Use a clean
project structure with a /data_sources folder for API wrappers, a /cache folder for a
local SQLite cache, and a /agents folder for the agent logic. Use Python 3.11+, requests,
and rdkit (install via pip with --break-system-packages if needed).

PART A — API wrapper modules (one file per source, each with its own function(s)):

1. orphadata.py — Orphanet rare disease list
   - Base: https://api.orphadata.com
   - Pull product1 (rare diseases + cross-references to ICD-10, OMIM, UMLS, MeSH)
   - Function: get_rare_disease_list() returns a list of dicts: {orpha_code, name,
     icd10, omim, mesh}
   - Also hardcode a static list of the ~20 WHO Neglected Tropical Diseases
     (e.g. Chagas disease, leishmaniasis, schistosomiasis, lymphatic filariasis,
     onchocerciasis, dengue, rabies, trachoma, Buruli ulcer, yaws, etc. — research
     the current official WHO NTD list and hardcode it as a Python list of dicts
     with name + any available MeSH/ICD-10 mapping)

2. open_targets.py — target-disease association
   - Open Targets Platform GraphQL API at https://api.platform.opentargets.org/api/v4/graphql
   - Function: get_target_disease_score(disease_efo_id) returns a list of
     {target_symbol, ensembl_id, uniprot_id, association_score} sorted descending
   - You will need to resolve disease name/MeSH/ICD-10 to an EFO ID first — Open
     Targets has a search endpoint for this, use it

3. chembl.py — bioactivity data
   - Base: https://www.ebi.ac.uk/chembl/api/data
   - Function: get_target_bioactivity_count(uniprot_id) — resolve uniprot_id to the
     correct SPECIES-MATCHED (homo sapiens only, unless explicitly told otherwise)
     target_chembl_id via /target?target_components__accession={uniprot_id}, then
     query /activity?target_chembl_id={id}&standard_type__in=IC50,Ki&
     pchembl_value__isnull=false&limit=1000, and FILTER to confidence_score >= 8.
     Return the count of qualifying records and the median pchembl_value.
   - IMPORTANT: never pool IC50/Ki values across different target_chembl_ids or
     across confidence_score < 8 without flagging it explicitly in the return value.

4. afdb.py — structure availability
   - Base: https://alphafold.com/api/prediction/{uniprot_id} (also mirrored at
     https://alphafold.ebi.ac.uk/api/prediction/{uniprot_id})
   - Function: get_structure_confidence(uniprot_id) returns {has_structure: bool,
     mean_pLDDT: float, model_url: str} — pull the per-residue confidence and
     compute the mean.

5. clinicaltrials.py — trial history
   - ClinicalTrials.gov API v2: https://clinicaltrials.gov/api/v2/studies
   - Function: check_prior_trials(drug_name, disease_name) returns a list of past
     trials with their status (COMPLETED, TERMINATED, WITHDRAWN, etc.) and a flag
     has_negative_repurposing_result if any trial for this exact drug+disease pair
     was terminated or showed no benefit.

6. pubchem.py — chemical structures
   - Base: https://pubchem.ncbi.nlm.nih.gov/rest/pug
   - Function: get_compound_data(drug_name) should resolve to InChIKey FIRST
     (via /compound/name/{name}/property/InChIKey/JSON), then use the InChIKey to
     pull CanonicalSMILES, MolecularWeight, XLogP — never match purely on name
     string for anything downstream of this function.

PART B — Local cache
Build a simple SQLite-backed cache (cache/cache.py) with get(key) / set(key, value,
ttl_days) functions. Every API wrapper function above should check the cache first
and write to it after a successful call. Use a hash of the function name + arguments
as the cache key.

PART C — Target Selection Agent (agents/target_selection.py)
This is the core deliverable of this stage. It should NOT use an LLM for scoring —
only for the final narration step.

1. Build the candidate universe: every Orphanet rare disease + every WHO NTD.
2. For each candidate disease, resolve to EFO ID and call Open Targets to get the
   top 5 associated targets.
3. For each (disease, target) pair, compute two SEPARATE scores (do not blend them):
   - tractability_score = weighted combination of: ChEMBL bioactivity count
     (capped, log-scaled), AFDB mean pLDDT for that target, and whether a prior
     trial already failed for this exact pair (large negative penalty if so)
   - unmet_need_score = based on whether the disease currently has zero approved
     treatments (check against Orphanet data fields if available; otherwise flag
     for manual review) combined with prevalence data if available from Orphanet
4. Output a ranked table (save as both JSON and CSV in /output) of the top 30
   candidate pairs with both scores shown separately, plus all the raw numbers that
   fed into them (so a human can audit the math).
5. ONLY after the table is built, make one LLM call (use the Anthropic API, model
   "claude-sonnet-4-6") to write a 2-3 sentence plain-English summary of why the
   top 5 candidates are interesting — the LLM must reference only numbers already
   in the table, and must not be asked to generate or revise any of the scores.
