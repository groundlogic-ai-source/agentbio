MEGA PROMPT 2 — Real biological/chemical enrichment + AgentBio as a tool

1. Build a bounded, explicit enrichment batch process (not autonomous
   unlimited spend) that reuses AgentBio's EXISTING wrapper functions --
   ChEMBL bioactivity/action_type, PubChem/RDKit descriptors and
   similarity, BioGRID, Reactome, Open Targets, and Boltz structure/
   binding-pose prediction -- to compute real chemical/biological
   features for drugs in the repoDB-derived dataset. Do not build new
   data-source integrations; call the exact functions the main pipeline
   already uses.

2. This enrichment tool must NEVER write to the production jobs table or
   explored_targets, and must never be presented as "AgentBio confirmed
   this" -- its only output is new, real, computed feature columns that
   then go through the exact same discovery/FDR/confirmation/confound
   pipeline as every other feature.

3. Cap and log real spend per enrichment batch (especially Boltz calls)
   and report total cost alongside the batch's results.

4. Run one new full discovery batch using the enriched dataset and report
   whether the resulting hypotheses look qualitatively different from
   the indication-name-keyword pattern seen in every batch so far.
