MEGA PROMPT A — Bisociative generation + discovery-phase testing

1. Apply the leave-one-out chronology fix above to produce the final
   labeled, feature-ready dataset from the already-verified repoDB +
   DrugCentral harness.

2. Bisociative hypothesis generation, using GPT-5.6 Sol via the OpenAI
   Responses API (confirm the exact model string with OpenAI's current
   docs before hardcoding it):
   - LLM A: propose 10-15 candidate predictor features inspired by an
     unrelated domain (e.g. network science, epidemiology, materials
     science), each reduced to something computable from the dataset's
     actual columns.
   - LLM B: propose a separate 10-15 features from a different unrelated
     domain.
   - Lead LLM (GPT-5.6 Sol): review both sets, combine/mutate them, and
     output a final list of concrete, computable hypotheses. Any
     hypothesis that cannot be reduced to a real, computable statistic
     from the dataset is discarded at this stage, not tested.

3. For each surviving hypothesis, pre-classify it as binary-predictor or
   continuous-predictor (fixed rule, decided before testing) and run the
   correct test:
   - Binary: Fisher's exact test, report odds ratio + 95% CI + p-value.
   - Continuous: logistic regression, report odds ratio + 95% CI +
     p-value per coefficient.
   All tests run ONLY on the discovery half of the split dataset.

4. Apply Benjamini-Hochberg FDR correction across the FULL batch of
   hypotheses tested in this pass. Report every hypothesis tested, its

   q<0.05 -- not just the survivors. Full transparency on what was tried
   and discarded is mandatory.

1. Re-test ONLY the FDR-surviving hypotheses from Prompt A, same test
